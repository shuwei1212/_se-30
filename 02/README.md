# 金門大學校務系統 Demo

一個類似金門大學校務系統的教學示範專案，使用 Node.js 內建模組實作，沒有第三方依賴。

提供學生、教師與管理員三種角色，包含登入、選課、課表、成績、課程管理與公告等功能。

## 快速開始

```sh
npm start
```

開啟 <http://127.0.0.1:3000>，使用下列示範帳號登入。

| 角色 | 帳號 | 密碼 |
|------|------|------|
| 學生 | `s11501001` | `1234` |
| 教師 | `t001` | `1234` |
| 管理員 | `admin` | `admin123` |

其他學生帳號：`s11501002` ~ `s11501004`、`s11401005`，密碼皆為 `1234`。
其他教師帳號：`t002`，密碼 `1234`。

## 功能

### 學生

- 儀表板：選課數、學分數、GPA、待評分課程、最新公告
- 選課：搜尋課程、選課、退選、額滿狀態、衝堂檢查
- 課表：以週一到週五、第 1-8 節呈現本學期課表
- 成績：成績明細、等第、積分與 GPA 計算
- 個人資料：學籍資料與選課紀錄

### 教師

- 儀表板：開設課程、修課學生數、待輸入成績
- 我的課程：查看課程與選課人數
- 成績輸入：檢視學生名單並批次儲存成績（0-100 分）
- 發布公告

### 管理員

- 儀表板：學生數、教師數、課程數、選課筆數
- 課程管理：新增課程、刪除課程、教師時段衝堂檢查
- 學生名單：檢視學生選課與評分狀況
- 發布公告

## 規則與驗證

- 登入後以 `sid` session cookie 維持登入狀態（8 小時）
- 未登入者一律導向登入頁；角色權限不足回傳 403
- 選課會檢查：
  - 是否重複選課
  - 課程是否額滿
  - 是否與已選課程衝堂
- 成績只接受 0 到 100 的數字，留空表示尚未評分
- 新增課程會檢查：
  - 課程代碼格式與重複
  - 學分、節次、人數上限範圍
  - 授課教師在同時段是否已有課程
- 重新導向會攜帶提示訊息，表單送出後採 POST-Redirect-GET，避免重複送出

## 環境變數

| 變數 | 說明 | 預設值 |
|------|------|--------|
| `PORT` | 監聽埠號 | `3000` |
| `HOST` | 監聽位址 | `127.0.0.1` |
| `DB_FILE` | 資料檔路徑 | `data/db.json` |

第一次啟動時會自動建立種子資料並寫入 `data/db.json`。

## 注意事項

本專案為教學示範用途：

- 密碼以明碼存在種子資料中，僅供展示
- session 存在記憶體中，重新啟動後需重新登入
- 資料儲存在本機 JSON 檔，不適合正式環境
- 若要用於正式系統，應改用資料庫、雜湊密碼、CSRF 防護與 HTTPS
